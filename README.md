# PigLauncher

An LSPosed module for providing modifications for POCO Launcher. Learn more about available modifications under the `Features` section.

The module only targets POCO Launcher (`com.mi.android.globallauncher`).

[![Latest release](https://img.shields.io/github/v/release/dinopig1219/PigLauncher?label=Release&logo=github)](https://github.com/dinopig1219/PigLauncher/releases/latest)

## Features

<details>
<summary>Press To Expand</summary>

- Unlock Dark Folder
  - Unlock dark appearence folder when the system is in Dark Mode. (available in HyperOS System Launcher but nuked in POCO Launcher)

- Unlock Advanced Textures
  - Unlock Advanced Textures effect to the launcher. (available in HyperOS System Launcher but nuked in POCO Launcher)

- Grid Folder Icon Fill
  - When a 2×2 or 3×3 folder contains exactly 4 or 9 apps, the last icon will display as a normal app icon size, and it is clickable to launch app.

- Fix Predictive Back Gesture Speed
  - Fixes the abnormal predictive back animation speed to restore the native speed.

- Unlock All Widgets Animation
  - Enables the back bouncing animation for all widgets.

- Hide Clear Recents Button
  - Hide the clear button in recents.

- Manage Home screen shortcuts (Hidden Apps Manager)
  - The module unlocked to let manage all app icon to show or hide.

</details>

> [!Note]
>
> 1. Initial development and testing are based on `RELEASE-6.01.05.2407-06081949`, `RELEASE-7.50.06.2592-09011644`
> 2. Tested with above versions on OS3 only. Compatibility with other POCO Launcher versions and OS versions may vary.

## How to Use

1. Install PigLauncher.
2. Enable PigLauncher in LSPosed.
3. Make sure POCO Launcher is included in the module scope.
4. Open PigLauncher and enable the features you want.
5. Restart POCO Launcher after changing module settings.
6. Enjoy!
